The fault model

Stuck-at faults

The single stuck-at model assumes one wire in the circuit is permanently tied to a fixed logic value: stuck-at-0 (s-a-0) or stuck-at-1 (s-a-1), while the rest of the circuit works. A circuit with n wires has 2n such faults. A test vector detects a fault when some primary output differs between the good circuit and the faulty circuit. That requires two things:

  • Excite (activate): drive the faulty wire to the opposite of its stuck value — set it to 1 to catch s-a-0, to 0 to catch s-a-1.
  • Propagate: sensitize a path so the difference travels to a primary output — every gate along the path needs its other inputs at non-controlling values.

Notation

Five-valued logic (Roth's D-calculus)

ATPG algorithms simulate the good and faulty circuit at once. Each wire carries one of five values — D means "1 in the good circuit, 0 in the faulty one":

SymbolGood circuitFaulty circuitMeaning
000wire is 0 in both
111wire is 1 in both
D10fault effect (excited s-a-0 shows D)
D̄01inverted fault effect (excited s-a-1 shows D̄)
X??not assigned yet

Gates compute on these values componentwise: evaluate the good parts and the faulty parts separately, then recombine. Inverting gates flip D to D̄ (e.g. NAND(D, 1) = D̄), and fault effects can cancel (XOR(D, D) = 0).

Reasoning forward

Forward implication

From known gate inputs, deduce the output. The key idea is the controlling value — the input value that fixes a gate's output on its own, no matter what the other inputs are:

GateControlling value cAny input = c ⇒ outputAll inputs = non-controlling ⇒ output
AND001
NAND010
OR110
NOR101
XORnone—output known only when every input is known

So AND(0, X) = 0 even though one input is unknown, but AND(1, X) = X. A fault effect propagates through a gate only when the other inputs sit at non-controlling values: NAND(D, 1) = D̄, but NAND(D, 0) = 1 — the 0 masks the fault.

Reasoning backward

Backward implication

From a required output, deduce what the inputs must be. An implication only exists when the inputs are uniquely determined:

ObservationUnique implication
AND out = 1  /  NAND out = 0every input = 1
OR out = 0  /  NOR out = 1every input = 0
AND out = 0  /  NAND out = 1nothing… unless all inputs but one are already 1 — then the last one = 0
OR out = 1  /  NOR out = 0nothing… unless all inputs but one are already 0 — then the last one = 1
NOT out = vinput = v̄
XOR out known, one input knownother input = out ⊕ input

ATPG interleaves both directions: assignments imply forward through the logic, objectives imply backward toward the primary inputs, and the process repeats until nothing changes (a fixpoint) or a conflict forces backtracking.

Putting it together

How a test is built

  1. Excite: set the fault site to the opposite of the stuck value; it now carries D or D̄.
  2. Propagate: the D-frontier is the set of gates with a D/D̄ input and an X output. Pick one, set its other inputs non-controlling, and push the fault effect one gate closer to an output.
  3. Justify: use backward implications to find primary-input values that produce every value you assumed. Conflicts mean backtracking and another choice.

Single-gate reps

Gate drills

One gate, some values hidden. Forward: compute the output from the inputs. Backward: from the output (and maybe one input), decide what each hidden input is forced to be — or mark it ? if several values remain possible.

Whole-circuit reasoning

Implication puzzles

The outlined values are given. Click other wires to cycle X→0→1 and fill in every value the givens force — forward through gates and backward toward the inputs. Leave a wire at X when nothing pins it down.
